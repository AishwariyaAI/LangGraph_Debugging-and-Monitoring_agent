# LangGraph Debugging and Monitoring Agent

A Python-based workflow monitoring application built with
LangGraph to track node execution, measure execution time,
capture exceptions, and generate monitoring reports.

## Features

- LangGraph workflow orchestration
- Node-level execution monitoring
- Execution-time measurement
- Error detection and logging
- Conditional routing after validation failures
- Monitoring reports
- Simulated error testing

## Tech Stack

- Python
- LangGraph
- Python Logging
